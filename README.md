# GameConfig Hub

Static Netlify website for managing game configuration presets locally.

## Demo accounts
- Admin: `admin` / `admin123`
- User: `user` / `user123`

## Important
This project is a configuration/preset manager only. It does not inject code, modify game memory, bypass anti-cheat, or alter game clients.

Data is stored in browser localStorage. For production authentication and shared admin data, use a real backend/database.
